# Portfolio

Personal portfolio of Rainy (jin3107) — a 3rd-year CS student focused on backend (ASP.NET Core) and React.

## Features

- Pages: Home, Projects, Contact
- Dark / light theme toggle
- Vietnamese / English (i18n)
- GitHub stats and top languages

## Tech stack

React 19, TypeScript, Vite, React Router. Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.

## Edit content

Projects and personal info live in `src/data/portfolio.ts`; texts for both languages in `src/i18n/translations.ts`.
